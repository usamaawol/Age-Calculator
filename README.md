🎂 Age Calculator Web App
A simple and interactive Age Calculator built using HTML, CSS, and JavaScript.
This app allows users to calculate their exact age in years, months, and days based on their birth date.

🚀 Features
📅 User-friendly date picker
⚡ Instant age calculation
🎯 Accurate results (years, months, days)
🎨 Clean and responsive UI
💡 Beginner-friendly project

⚙️ How It Works
User selects their birth date
Clicks the "Calculate" button
The app calculates the difference between current date and birth date
Displays the result in:
Years
Months
Days
📦 Installation & Usage
Clone the repository:
git clone https://github.com/usamaawol/age-calculator.git
Open the project folder:
cd age-calculator
Run the app:
Open index.html in your browser
OR
Use Live Server in VS Code
